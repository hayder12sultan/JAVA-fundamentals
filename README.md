# Java Fundamentals

A collection of simple Java examples covering essential programming concepts.

## Topics Covered
- Variables and Data Types
- Mathematical and Logical Operators
- Conditional Statements
- Loops and Arrays
- Methods and Parameters
- Object-Oriented Programming (OOP)
- Strings and Common Methods
- ArrayList and HashMap
- Exception Handling
- Type Conversion and Wrapper Classes
- Enums and Constants
- Ternary and Switch Expressions
- Lambda Expressions
- Date, Time, and File Paths

## Run the Examples

```bash
javac Main.java
java Main
```

**Requirements:** Java 17 or newer.

## Purpose

Practice Java fundamentals through simple, readable examples with expected outputs.
